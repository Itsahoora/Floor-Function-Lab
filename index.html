The rule

⌊x⌋ = n  ⟺  n ≤ x < n + 1

Each point rolls left and falls into the first pit it meets. The pit is the greatest integer less than or equal to the original value. That is why ⌊−7/2⌋ = −4, not −3.

FLOOR FUNCTION LAB · PRESENTATION

The floor function

⌊x⌋ = n  ⟺  n ≤ x < n + 1

The floor of a real number is the greatest integer less than or equal to that number.

⌊−3.5⌋ = −4

−4 ≤ −3.5 < −3
